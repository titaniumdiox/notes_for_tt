# Momo 场景素材库

- 尺寸：1440×2560 PNG（9:16）
- 生成方式：Momo 设定图作参考 + Ark Seedream 5.0 Flash 逐页重绘
- 图内全部无文字；p01-v1 例外（有店名，做封面时遮挡）
- 所有版本保留，最终按页面分配

## 注意

- `p02-v1` 没吸管，用户已确认无伤大雅；后期可补。
- `p03-v1-index` 的单指手势可能被部分观众误读；如果正式投放，`p03-v2` 更安全。
- `p04/p06/p08` 是柜台半身，`p03/p05/p07` 是全身；如果要求统一，可只重跑这三张。
- 所有图内文字叠加都由代码完成，不再让模型写字。

## 生成脚本

```powershell
python production/assets/mascot/generate_scene.py `
  --prompt production/assets/mascot/scene-p04-prompt.txt `
  --out production/assets/mascot/scenes/p04-v1.png
```
