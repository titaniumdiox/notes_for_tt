# 奖励语词库

数据表：[rewards.csv](rewards.csv)（36 条，UTF-8 with BOM，可直接用 Excel 打开）

## 列说明

| 列 | 含义 |
|---|---|
| `id` | 稳定 ID；脚本里只引用 ID，不直接写句子 |
| `category` | calm / warm / food / sports / travel / final / cute |
| `zh` / `pinyin` | 显示与注音 |
| `en` / `es` | 内部参考；是否上屏由当期决定 |
| `energy` | 1–4；1 最 calm，4 最像比赛 |
| `tts_rate` | 奖励语相对语速；人声用 |
| `target_sec` | 目标时长，不是硬切时长 |
| `scene` | 适用题材 |
| `position` | `after_answer` / `transition` / `final` |
| `voice` | calm / warm / bright / punchy / playful |
| `visual` | 配合的视觉反馈 |
| `notes` | 使用限制 |

## 语速规则

- **词音**：`0.95×`，清楚但不拖
- **问句 / 例句**：`0.90×`，教学示例稍慢
- **最终整句**：`0.92×`
- **奖励语**：`1.04–1.12×`，短、亮、上扬
- **运动/比赛**：`1.10–1.12×`，更短更冲
- **平静教学**：`0.98–1.00×`，不要喊

> 不要整条视频统一 1.0×。词、例句、奖励语应该有三种语速。

## 轮换规则

1. **60 秒内最多 5 次奖励，建议 3–5 次。**
2. **相邻两次不重复**；同一句一条视频只用一次。
3. 第 1 次奖励用 `warm`，第 2–3 次用 `calm`，最后一次用 `transition`/`final`。
4. `transition` 类（R09/R10/R17/R21/R25/R26）不是夸奖，是“继续”的指令。
5. 场景词只在对应场景用：`好球` 不进奶茶店，`点单成功` 不进运动场。
6. 成人教学慎用 `cute`；如果 Momo 没有固定角色声线，R35/R36 先不用。

## 脚本引用格式

```json
{
  "reward": {
    "id": "R07",
    "at": "answerEnd+0.2",
    "visual": "star"
  }
}
```

不要把 `zh` 直接写进页面代码；只写 ID，渲染时从表里取。这样换题材只换 ID。

## 音频生成

- 每条单独生成，不要拼接成一条长音频
- 文件名：`rewards/R07-zhēn-bàng.wav`
- 人声 + 一个原创短音效；不要直接使用 Candy Crush 音效
- 奖励语比旁白高 1–2 dB，整体仍控制在 -16 LUFS 左右
- 生成后必须试听：短句最容易出现声调/多音字错误
