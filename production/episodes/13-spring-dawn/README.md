## 诗

```text
春眠不觉晓，
处处闻啼鸟。
夜来风雨声，
花落知多少。
```

```text
Spring sleep — I wake to morning sun,
Birds are singing, one by one.
Last night came the wind and rain,
How many blossoms fall again?
```
