## 关键发现

1. **食物类内容量最大，但文化解释最少。**  
   202 条里，严格可解释的只有 40%；大量是 ASMR、mukbang、吃播、无描述展示。

2. **“美食号”不是账号方向。**  
   纯食物展示可以带来播放，但很难承载“文化差异”与“轻量中文”；必须加一个“为什么”。

3. **食物是很好的“入口”，不是终点。**  
   同一道菜可以拆成：
   - 为什么中国早餐是热的/咸的？
   - 为什么街头小吃这么便宜？
   - 为什么中国人合餐、夹菜、劝菜？
   - 为什么同一道菜在不同省份完全不一样？
   - 为什么中国菜在美国被改造？

4. **旅行内容可以借食物落地。**  
   西安回民街、武汉巷子、上海南京路、广州北京路等样本，适合做“城市 + 食物 + 一个文化点”的组合，而不是纯吃播。

## 对内容策略的调整

饮食支柱保留，但采用“**食物 + 为什么**”格式：

- 不发布纯食物蒙太奇；
- 每条至少回答一个“为什么”；
- 中文点只放一个词，例如“路边摊”“早餐”“合餐”“劝菜”；
- 视觉上用“食物特写 → 场景 → 原因”的三段式，避免变成美食探店。
