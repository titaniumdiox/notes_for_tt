## 4. 已出现的选题类型

从 17 条直接对比样本里，可以归纳出 6 类高潜力角度：

### A. 日常规范与礼貌

- “在美国正常、在中国却不正常的三件事”
- 对长辈的称呼、孩子命名规则
- 公共场合的吐痰/咳嗽行为
- 排队、公共空间边界

这类最适合做**场景插画 + 旁白对比**，冲突点清楚，不需要真人出镜。

### B. 身体与生活习惯

- 午饭后躺平/午休文化
- 喝热水、养生、坐月子（后续可专门搜）
- 吃饭时的分享与夹菜

这类能直接回答海外观众“为什么中国人会这样”。

### C. 语言与社交反应

- 外国人一说中文，店员/路人的反应
- 中国人对“直接赞美”和“客气”的处理
- 社交距离、朋友边界、面子

适合做**小剧场动画**：一句中文引发不同反应，天然有戏剧性。

### D. 家庭与代际

- 婚姻压力、催婚
- 父母对成绩/稳定的重视
- 三代同堂与边界感

这类情绪强，但要注意避免刻板化；用“具体家庭场景”而不是“中国人全都这样”。

### E. 消费与旅行反差

- 中国 vs 欧洲的旅游纪念品差异
- 中国城市的“未来感”与日常便利
- 移动支付、外卖、快递、夜间安全

适合“第一次来中国的人最震惊的 5 件事”这种清单式短视频。

### F. 饮食作为文化入口

- 早餐、外卖、奶茶、菜市场
- 合餐 vs 分餐
- “为什么中国人不喝冰水”

注意：纯美食展示的相关性只有 1 分；必须加“为什么/对比”才有文化差异价值。

## 5. 对内容生产的建议

账号主线**不收缩为单一“文化差异”赛道**。保留日常生活、旅行、饮食、语言、家庭、工作消费、乡村/科技等多支柱；文化差异作为高频叙事角度：

> **同一件小事，中国和世界为什么会做得不一样？**

推荐的内容结构：

1. **3 秒钩子**：一个反常识场景，例如“在美国，孩子直呼长辈名字很正常；在中国，这可能被视为没礼貌。”
2. **场景对比**：左边/右边，或“我以为 vs 实际”。
3. **解释原因**：家庭结构、集体主义、面子、历史习惯，但控制在 1–2 句。
4. **轻量中文点**：只放一个关键词/一句话，不做教材式教学。
5. **结尾提问**：引导海外观众评论“你们国家呢？”

视觉上适合：

- 2D 场景插画/简化动画；
- 固定角色 + 左右对比构图；
- 中英双语大字卡，但中文只做“关键词”；
- 不需要真人短句口播。
