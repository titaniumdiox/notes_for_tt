## 高潜力样本

9 条直接有洞察的内容，指向这些方向：

1. **在深圳住两年后的本地推荐**：生活经验型旅行
2. **河北美院“中国霍格沃茨”**：建筑/审美好奇点
3. **来华前以为知道，实际每天仍被惊讶**：预期反差
4. **重庆视觉冲击 + 中美对比**：城市气质
5. **来华四次后的真实感受**：长期观察
6. **中国旅行指南 + 来之前希望知道的事**：实用差异
7. **黄金周 21.3 亿人次**：社会/旅行观察
8. **上海买包砍价故事**：真实文化互动
9. **来华前须知：App/支付差异**：实用文化差异

这些比“重庆赛博朋克打卡”更适合做 CN Fieldnotes，因为它们有**人的经验**或**具体的文化摩擦**。

## 关键发现

1. **旅行素材量最大，但“好看”不等于“有内容”。**  
   255 条里，严格有文化/实用洞察的只有 30%；大量是风景、打卡、行程清单。

2. **旅行内容最适合做 B-roll，不适合做主线。**  
   纯风景镜头可以当背景，但主叙事必须落到：
   - 一个文化点（为什么中国城市这样规划/生活）
   - 一个实用差异（App、支付、交通、排队）
   - 一个预期反差（第一次来中国 vs 想象）

3. **“第一次来中国”是强钩子。**  
   预期反差、踩坑、文化摩擦，比“这里好美”更容易引发评论。

4. **城市对比可以做系列。**  
   上海、重庆、深圳、成都、县城，同一个国家不同气质；适合地图 + 场景插画。
