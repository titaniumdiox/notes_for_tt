关键结论：

1. **203 不是“最后一页”信号。** 它在第二个关键词里出现在第 1、2 页，且数据可用；不能按页码判断，也不能只看状态码。
2. **不同关键词的池子大小不同。** 一个 3 页耗尽，一个 4 页耗尽；固定“5 页”目标不现实，应以 `has_more`/`cursor` 为准。
3. **相关性没有明显崩掉。** 两个词的相关 + 邻近都在 90% 以上，当前筛选规则可以继续用。
4. **仍然只是同一时间窗口。** 还没有跨小时/跨天复跑，不能排除时段性推荐波动。
